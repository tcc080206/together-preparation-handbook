# 手冊閱讀設計與驗收

本文件記錄歷次設計與當時的驗收結果。目前的專案位置與檢查指令見[共用手冊 README](../frontend/README.md)，下一版導覽見[導覽與閱讀設計](../frontend/NAVIGATION_DESIGN.en.md)。

以讀者要解決的問題決定版型。首頁包含分章索引，分類頁直接呈現文章標題，較長的分類依具體任務分組。[分類頁設計](NAVIGATION_DESIGN.en.md#分類頁改版)列出舊篩選網址的相容行為。金額在同一張表內對齊情境與子女序位，直接限制放在表旁。完整欄位與來源一次閱讀一筆。未收錄公共資料的事項提供編輯提問，依主題使用情境切換、步驟或討論單。個人安排採狀態、排序與分頁，設定與編輯使用表單。

前版以深藍 #173850 作書封與標題、湖綠 #146962 作閱讀選取色、淺藍 #eaf3f7 作比較底色、琥珀 #865317 表示資料缺口、白 #ffffff 作內頁。標題採宋體，控制項和欄位採系統黑體，金額採等寬數字。桌面封面和內容並讀，手機依標題、選擇、結果、行動排列。維持文字可換行，資料筆數增加時分頁或切換記錄。

## 混合風格改版

設計交付條件是定義全站共用色彩、字體、焦點、表單和表面樣式，並指定首頁與文章的桌面、手機和資料狀態。以下色彩和版型取代前版視覺規格。使用 Soft UI Evolution 的暖白、鼠尾草綠、蜜桃色與輕陰影。首頁以 Bento Grid 呈現五個階段、備孕章節與常用資源。文章使用 Editorial Grid 的窄閱讀欄、章節導覽、引文式重點、分隔線和來源資訊。無資料顯示待補並保留可進行的提問，連線錯誤沿用重試。

## 資料待補交付

中央比較切換項及行列在無記錄或單格金額缺失時仍可閱讀。單格已有發布記錄但欠金額時，可從「待補」開啟該筆條件和來源。所選縣市在文章下方原範圍位置顯示地方狀態，有地方記錄時可從該位置開啟。整個事項無發布資料時保留原提問、資料狀態和加入安排。兩個比較頁若全空，仍保留比較表，提問可從文章目錄切換。延用同樣的手機欄位與桌面閱讀欄，服務失敗沿用重試。

本次交付以 [缺口對照](../data_validation/research/HANDBOOK_GAPS.md) 及 [工作卡](../data_validation/research/HANDBOOK_WORK_ORDERS.md) 為交接範圍。確認 31 個事項、每個已辨識缺口的原位置及派工、空值與縣市狀態、核准和撤回、服務重試，以及現有手機／桌面版面和個人安排。資料採集、人工核對、匯入及部署屬後續作業。

| 驗收項目 | 結果 | 實際驗證 |
| --- | --- | --- |
| 事項、欄位、情境及派工 | 通過 | 唯讀 API 有 31 個事項、23 筆發布記錄。中央比較四格待補，逐一核對臺灣 22 縣市的 176 個地方狀態。31 個事項和縣市表均有結果或卡號，檔案連結及工作卡錨點已驗證。 |
| 部分資料及完全空白 | 通過 | 瀏覽器攔截回應驗證全空事項、金額空值、整個比較情境缺失、中央有值而地方缺失，以及全空比較頁的原提問與安排。 |

## 四個階段的閱讀入口

延伸混合風格。首頁 Bento 卡片使用各階段的簡介，階段頁沿用共用標題、紙面、章節選取色與焦點樣式。桌面在窄閱讀欄旁呈現章節選擇，手機依標題、章節、內容、行動排列。預設顯示費用與支持並展開第一個問題；首頁產前檢查直接選取懷孕的健康章節。其他章節依序是健康與生活安排。同一章一次展開一題，每題可儲存並沿用既有安排編輯器。共享文章使用原事項網址與可回復的階段、章節參數，並標示原文範圍。

設計交付條件為定義以上版型、導覽及選取規則，以及資料與行動的對應。新增提問為編輯內容；公共資料沿用已發布文章及唯讀 API。資料缺失時保留提問及安排，縣市缺口與中央方案分開呈現，金額及日期分別顯示「待補」及「待確認」，讀取失敗沿用重試。

### 首頁五階段導覽

首頁階段卡一律先選取階段，並將焦點移到同一個章節區。桌面章節位於左下方，手機排在階段卡之後、常用資源之前。預設顯示備孕原有章節，其他四個階段顯示依費用與支持、健康、生活排列的三個入口。點選章節才進入閱讀頁。階段選擇可從網址恢復，切回備孕時保留既有章節選擇。首頁常用資源沿用各自的直接入口。

驗收涵蓋全部五張卡。以滑鼠與鍵盤選取階段，確認仍在首頁、階段高亮、章節區取得焦點，再開啟章節並測試返回與重新整理。以八種視窗重跑版面檢查，維持三屏上限和零整頁水平溢出。變更範圍為首頁選擇與章節導覽。

實測通過。390×844 與 1440×900 的五個選取狀態均確認焦點、章節位置及高亮，axe 未報違規。鍵盤可走完五條選取、閱讀、返回及重新整理的流程。八種視窗各量測 498 個畫面狀態，最高 2.81 屏，整頁水平溢出為 0。Python、Node 語法檢查及瀏覽器測試通過。
