# 一起準備五階段實作驗收

入口為 [http://localhost:8780/](http://localhost:8780/)。五個階段各自維護章節、提問和指南參照，共用同一個伺服器和閱讀器。搬移前盤點了 31 個事項 ID、8 個目錄分類、四個既有階段的 20 個提問鍵、舊網址與 `together-preparation-v1` 個人儲存。原提問鍵保留，新增產檢自費提問。

| 驗收 | 結果 | 實際證據 |
| --- | --- | --- |
| I1 首頁與章節 | 通過 | Chrome 以 390×844 鍵盤及 1440×900 滑鼠選取五階段。測試涵蓋章節區焦點、15 個章節入口、三章的 3／4／1 個備孕分類，以及健康分類篩選、開啟文章、返回篩選與發起連結焦點。 |
| I2 同等版型與快捷入口 | 通過 | 兩種尺寸對五個選取狀態逐一比對未選卡與資源按鈕的背景、字體、欄位跨距及寬度。驗證單一選取、底線、文字對比，並從每個狀態開啟同一篇育兒補助文章後返回。 |
| I3 孕期產檢 | 通過 | 在手機和桌面隔離瀏覽器切換未對應、中央有資料、中央加所選縣市、院所自費、金額與日期空值。驗證健康章直達同一主題，縣市待補與中央記錄分開，另開啟來源網址與頁段。 |
| I4 產後與新生兒路徑 | 通過 | 由產後及育兒費用章開啟同一個具名報價 fixture，核對記錄 ID、每晚單位、取消條款和空價格，切換三種方式，驗證新北縣市篩選排除臺北報價及返回育兒的焦點。既有育兒及幼兒園比較涵蓋在瀏覽器回歸。 |
| I5 各階段與發布門檻 | 通過 | 兩種啟動指令各開啟全部 15 章。Python 暫存資料庫驗證部分核對、完整核對、欄值改動及撤回。瀏覽器 fixture 驗證重載後撤回的中央、地方與報價記錄回到資料缺口，保留提問和來源欄位空值。503 修復後以鍵盤重試。 |
| I6 相容性與個人安排 | 通過 | 隔離 Chrome 檢查舊數字章節搭配階段或錨點、舊方案連結、文章分頁錨點、`question=none`、舊提問、瀏覽器上一頁、重載及篩選回程。比對舊安排的日期、負責人、優先、狀態、備註與順序，並重載新增和編輯項目。 |
| I7 手機、桌面與操作 | 通過 | Chrome 在八種尺寸各跑 59 個路徑、501 個狀態，共 4,008 次量測。另量測 16 個展開的產檢與產後記錄 fixture。兩組合計最高 2.78 屏，整頁零橫向溢出。鍵盤涵蓋章節、提問、記錄選單、來源、重試與儲存，另查核焦點、原生展開狀態和減少動態。 |
| I8 階段來源及 API | 通過 | 以相同暫存資料庫直接執行 `snapshot()`，與 API 移除 `stages` 後的結果逐值比對。暫存孕期階段檔修改一個副標後重載，API 及畫面只出現這一個階段副標變動。 |
| I9 共享提問與錯誤恢復 | 通過 | 修改暫存產後檔的提問文字後，兩個入口重載皆顯示改字。兩條入口都使用 `stage_postpartum_home-budget`，個人儲存只有一筆。重複提問鍵、重複準備單歸屬、懸空主題與無效 JSON 各觸發帶檔案定位的 503，修復後按重試恢復。 |
| I10 雙入口 | 通過 | 在 8780 依序啟動 `frontend/server.py` 及 `before_p/server.py`。同一隔離瀏覽器驗證 5 個階段 ID、15 章、舊事項及提問連結、原個人安排及唯讀快照逐值相同。直接請求階段檔、伺服器原始碼與資料目錄檔案得到 404。 |

## 驗證命令

- `python3 -m unittest discover -s frontend/tests` 在專案虛擬環境通過 1 項發布門檻測試。所有 `frontend/web/*.mjs` 及 `frontend/tests/*.mjs` 通過 `node --check`，三個 Python 服務模組通過 `py_compile`。
- `node frontend/tests/handbook_ui.mjs` 使用 `HANDBOOK_URL=http://localhost:8781`、Playwright、Chrome、暫存快照及獨立瀏覽器工作階段。
- `node frontend/tests/stage_launchers.mjs` 通過雙入口、暫存階段檔異動和錯誤恢復案例。
- 截圖位於 `/tmp/handbook-stages-test/screens/chromium/`，包含兩種尺寸的五個首頁選取狀態、產檢待補與已核對 fixture、產後報價 fixture。

## 本機公共資料

本機 API 有 8 個分類、31 個指南、50 筆已核對記錄。移除新增的 `stages` 欄位後，與搬移前擷取的 API 值完全一致。備孕健檢、中央生育支持、育兒與幼兒園比較沿用已有記錄及地區範圍。

孕期的 `prenatal-coverage`（產檢公費與補助）和產後的 `postpartum-care-options`（月子中心、到宅照護及家人協助）尚待公共資料目錄建立指南對應。自費產檢與院所住院估價也以資料待補和準備提問呈現。驗收的產檢項目與具名報價來自隔離 fixture。孕期準備清單保留為採集背景，正式數值、價格及醫療時程仍由 `data_validation` 採集和核對。
