# 手冊缺口補充工作卡

依[前端對照](HANDBOOK_GAPS.md)、[原工作卡](WORK_ORDERS.md)、[來源路線](SOURCE_MAP.md)、[單卡流程](EXECUTION_GUIDE.md)及[交付契約](DELIVERY_SPEC.md)派工。金額優先，其次健康與準備內容。已有證據先用原工作包。以下 C15-GENETICS 沿用原卡 ID 續查。

## 每卡共同到件條件

- 只處理指定情境。卡片列出手冊事項與可用分類；新指引優先使用最後的專用分類，既有記錄沿用原分類與穩定 ID。同一來源涵蓋多處時，在 MAPPING 逐一列出位置；未有既定跨事項映射時交人工確認。通用指引用 TW；地方或院所用具體縣市 ID，一次派一個指定縣市。現行案件查執行當日生效版本，並保存適用期間；招生保留公告學年度。
- 每筆附提供者、適用對象、地區、數值／內容、官方單位、有效起迄、條件、限制及實際核對日。來源存標題、原件 URL 和可重查定位（條、頁、表列、段落或附件名）。缺值用 null，保留官方原單位及明列的不同費用性質。口徑衝突時保留各版本、雙方原件定位和受影響欄。
- 工作成果存 `data_validation/work/<卡號>/<YYYY-MM-DD>-<run>/`。交 REPORT、EVIDENCE、MAPPING、CHANGES、SNAPSHOTS、raw、合法 candidate JSON，新增候選與既有更新提案分開。當原件可定位、欄位及情境可逐一核對、地域與期間可區分時交人工核對。沒有找到時於 REPORT 記日期、官方站點及關鍵字、未決欄和下一個線索；查無結果仍維持未知。候選保留在 work。
- 重用卡依原報告定位證據；續查只處理下方已知缺口。範圍上限與工作包驗證依單卡流程及交付契約。
- H05-CARE、H26-APPLY 列出每個已發布方案的穩定 ID 與適用的辦理流程。要替既有記錄增補欄位時，以 CHANGES 與 MAPPING 交更新提案。已發布項目原值與核對狀態由後續接入流程管理。
