# 資料核對平台

正式工作目錄為 `data_validation/`；目前以本機單人模式使用。資料庫、核對紀錄與歷史持續保存在 `data/`，升級時請保留整個目錄。

從工作區根目錄啟動：

```sh
uv run --project data_validation python data_validation/server.py --port 8790
```

開啟 http://localhost:8790/allowance 、 http://localhost:8790/childcare 或 http://localhost:8790/preschool-fees 。僅監聽本機，單人使用。

左側分頁顯示核准狀態與已核准／總欄數。✅ 表示所有重要欄位都已儲存為正確且對應目前資料；⏳ 表示尚未全部核准，空分類另顯示尚無資料。未儲存草稿與尚未套用的錯誤修正不計為核准。

勾選「只顯示未全部核准」可隱藏已完成分頁，選擇會保留至下次開啟。篩選只影響左側清單，不切換主頁或清除草稿。儲存／套用後立即更新狀態；新增JSON資料後重新整理，該類會重新顯示為未全部核准。

左側切換類型；既有兩類只核對金額、條件、限制，新分類依review_fields設定。其餘資料及官方來源可展開查看。

1. 點選 ⏳（未核對）／✅（正確）／❌（錯誤），錯誤時填正確值。可按「✅ 全部正確」將本頁所有重要欄位標正確，包含篩選隱藏項目；這會取代原本的錯誤標記，仍須儲存才生效。選項只有emoji，滑鼠提示與無障礙名稱保留狀態文字。
2. 按「儲存本頁核對」，一次保存本頁變更；篩選隱藏的草稿仍保留並一起儲存。
3. 按「🔄 套用修正」，更新本頁已儲存且尚未套用的錯誤欄位。畫面立即顯示更新後資料，該欄自動改為 ✅，並收起修正輸入。原錯誤判斷與修正前後值保留在歷史。未儲存時不可套用。
4. 下方「修改紀錄」查看核對及套用的前後值、時間與操作者。完整資料庫另保留批次與舊版歷史。

## 資料與歷史

- `data/platform.sqlite3`：唯一的目前主資料。`records` 是目前政策資料；`reviews` 是最新核對、依據原值及套用時間；`events` 是追加的修改歷史（操作種類、批次、前後值、時間、local-user操作者）；`meta` 是整體版本。沒有登入，所以操作者不是經認證身份。
- `data/records.json`：初始匯入快照，保留原值；啟動後修改此檔不會覆寫SQLite。
- `data/reviews.json`：舊版核對資料。首次建立SQLite時自動匯入最新結果與完整history，不更改或刪除舊檔，之後不再寫此檔。舊背景欄位核對仍留在資料庫，不加入新核對／套用流程。
- `data/imports/*.json`：新增批次入口，重新整理自動驗證匯入。
- `categories`與`imports`資料表：分類設定、已匯入批次ID、雜湊、檔名及JSON原文，保存在同一SQLite。
- `data/moe-amount-source.pdf`：教育部數額表來源快照。
- `server.py` 與 `web/`：Python標準函式庫及原生HTML/CSS/JavaScript。

每次儲存或套用使用一個SQLite交易；整批失敗時不寫入任何部分。資料版本過期回傳409，避免舊頁覆蓋較新資料；先保留自己的草稿內容，再重新載入核對。套用前核對原值，已套用記錄不重複套用。修正不更改官方核對日期，也不自動視為完整資格通過。

備份時停止服務後複製整個data/目錄。原始JSON與事件歷史均保留；目前沒有一鍵回復介面，可重新核對輸入舊值再套用，留下完整回復紀錄。

此處「套用」更新本平台SQLite主資料，before_p 重新整理時會唯讀載入已通過人工核對的記錄，入口及採集需求見 [備孕手冊接入](BEFORE_P.md)。目前共85筆、29分類：原30筆保留，另新增中央托育一般／特殊身分及延長補助18筆、雙北地方托育增額6筆、具名托育原費用4筆與自付待查2筆、臺北生育補助3筆與國保生育給付2筆、育嬰給付公式2筆、雙北孕前檢查6筆、臺大AMH及基因諮詢3筆，以及招生／候補／留停權利9筆。新55筆的165個重要欄初始未核對。

## 之後新增資料

1. 參照 [JSON範例](examples/new-category.json)，填入分類設定、資料與來源。
2. 存入 `data_validation/data/imports/任意檔名.json`。
3. 重新整理網頁，新分類自動出現在左側；同分類的新資料進原頁。無須修改程式或重啟。

核對、全部正確、整頁儲存、套用後轉正確與歷史全部共用。錯誤檔案在頁面顯示原因，不覆寫既有內容；已匯入批次不可修改，新增資料使用新batch_id與穩定的新record id。範例是格式示意，請先替換內容及來源，不會自動匯入。

完整格式、限制及範例見 [新增資料與分類接入規範](ADDING_DATA.md)，後續工作規則見 [AGENTS.md](AGENTS.md)。

幼兒園頁面：`/preschool-fees`，批次為 `data/imports/preschool-fees-20261114-001.json`。依行政院《我國少子女化對策計畫2.0（115–118年）》表5-3-3、5-3-7整理中央上限，額外費用與地方減免另計；來源與限制可在各筆資料展開查看。新資料36個重要欄位預設未核對。
